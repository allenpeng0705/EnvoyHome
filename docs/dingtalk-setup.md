# EnvoyHome — DingTalk Chat setup

| Item | Value |
|------|--------|
| Channel id | `dingtalk` |
| Kind | `chat` (单聊 / Stream Mode) |
| Secrets | `clientId`, `clientSecret` |
| Settings | Connections → Channels |

1. Create a DingTalk open app / robot with Stream Mode.
2. Paste Client ID + Client Secret — config autosaves and enables.
3. 1:1 message the robot → link `senderStaffId` under **Link a sender**.

Group messages are ignored (Chat only).
