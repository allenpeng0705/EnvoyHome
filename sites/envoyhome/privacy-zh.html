隐私政策

最后更新：2026 年 11 月 11 日 · 适用于 EnvoyHome 桌面设置外壳、手机轻客户端，以及你自行运行的守护进程。手机包名：com.envoymesh.envoyhome。

EnvoyHome 是自托管的。对话、记忆、文档与智能家居控制都运行在你的家庭守护进程上——而不是 EnvoyHome 的云端大脑。本页说明软件会处理哪些数据、数据流向何处，以及发布方不收集什么。

1. 一句话说明模式

智能体运行在你控制的电脑上。桌面和手机是轻客户端：它们通过 home.* 通道连接那台守护进程，并显示它返回的结果。没有 EnvoyHome 注册，也没有一个强制性的厂商云在接收你的家庭对话、Home Assistant 令牌或模型 API 密钥。

谁负责？在自托管模式下，运行家庭机器的个人或家庭决定存储哪些数据、配置哪些可选提供商。发布方提供软件，但不运营你的守护进程。

2. 留在你机器上的数据

  • 对话与会话。会话记录、工具调用和回合产物保存在家庭电脑上的守护进程状态目录中。
  • 记忆。档案事实、常驻笔记、每日记录、情景索引，以及你接受的学习提案，都按家庭账户保存在本地。
  • 文档。放进 knowledge/ 的文件及其按账户建立的 SQLite 索引留在家庭机器上，不会上传到 EnvoyHome 服务。
  • 密钥。模型提供商密钥、渠道机器人令牌、智能家居凭据和设备私钥由守护进程保存。手机和桌面收到的是结果，而不是存储的密钥。
  • 审批与授权。待审批记录和授权按账户持久化为文件，重启不会让问题悄悄消失。

4. 推送通知

如果你启用通知，守护进程会在需要审批时通过 iOS 的 Apple 推送通知服务（APNs）或 Android 的 Firebase Cloud Messaging（FCM）发送事件。这些平台会收到投递通知所需的推送内容和设备令牌。在 Android 上，只有构建包含 google-services.json 时才会使用 Firebase；此时 FCM 是消息服务。

5. 配对与网络访问

手机通过扫描桌面设置中生成的二维码配对，或手动输入守护进程端点。iOS 需要“本地网络”权限才能访问局域网地址。配对会把设备绑定到特定的家庭账户；设备不能代表未绑定的账户行动，绑定关系无法解析时守护进程会拒绝请求。

6. 可选的模型与工具提供商

EnvoyHome 可以运行本地模型（llama.cpp 或 Ollama），也可以调用你配置的提供商，例如 OpenAI 兼容或 Anthropic 兼容端点。当你使用云端提供商时，当前回合所需的提示与上下文会离开家庭机器，并按该提供商的条款处理。这可能包括为该回合检索到的文档或记忆片段。对话与会话可能发送给你选择的提供商；发布方不是该提供商。

隐私模式是一个硬开关：它强制本地推理，并拒绝网页搜索、网页调研、浏览器、HTTP 抓取、页面提取、远程 MCP、图像生成和消息发送等云端工具。开启智能家居出网阻断后，它还会拒绝 Home Assistant / MQTT 的设备动作与事件源通知。

浏览或抓取网页的工具会从家庭机器访问第三方网站。这些网站会像收到普通浏览器请求一样收到该请求，并适用它们自己的隐私政策。

7. 智能家居数据

Hub 凭据和 broker 密码留在守护进程上。设备状态、摄像头、门锁与存在数据被视为敏感：敏感结果会强制该回合使用本地推理，而不是发送给云端提供商。设备状态不会自动进入常驻记忆。EnvoyHome 与你的 hub 集成，不运营自己的智能家居云。

8. 发布方不收集什么

  • 自托管产品不要求注册账户、邮箱或手机号。
  • 没有厂商运营的家庭对话、记忆、文档或智能家居令牌存储。

9. 保留与删除

  • 撤销设备：在桌面或手机的 Owner 设置中撤销，凭据将无法再打开会话。
  • 删除本地历史：在应用中删除，或移除守护进程状态目录里相应的会话与记忆文件。
  • 卸载手机应用会移除手机本地数据，但不会删除家庭电脑上守护进程的数据。
  • 清空守护进程状态目录可移除本地记忆与已存令牌。操作前请先备份需要保留的内容。

10. 儿童隐私

EnvoyHome 不面向 13 岁以下儿童，也不面向你所在司法辖区规定的最低年龄以下的用户。请勿在缺乏适当监督的情况下为儿童创建家庭档案。

11. 你的选择

  • 选择纯本地推理，或开启隐私模式以阻断云端工具，并可选地阻断智能家居出网。
  • 决定哪些文档进入知识库，以及配置哪些可选的提供商、渠道和 MCP 服务器。
  • 通过 PendingLearn 接受或拒绝记忆与技能变更，它们才会持久化。
  • 撤销配对，收回某台设备的访问权限。

12. 政策变更

随着预览版演进，本政策可能更新。页面顶部的日期是当前版本的有效日期。若提交公开商店上架，重大变更会先反映在本页。
